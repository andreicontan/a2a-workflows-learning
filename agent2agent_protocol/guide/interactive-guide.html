What Is This Project?
Learn ▶

This project uses AI agents that talk to each other to automate software development. Instead of one big AI doing everything, we have small, focused agents — each an expert at one thing.

Think of it like a software team:

Analyst
"What do we need?"
➜
Tester
"Write the tests"
➜
Developer
"Write the code"
➜
Reviewer
"Write the MR"

Each "person" is an AI agent running as its own web server. They communicate using A2A (Agent-to-Agent), a protocol created by Google.

It's faster because agents run in parallel
Each agent is an expert at one thing and can be swapped independently
It uses less memory
It doesn't need an API key

Key Concepts
Learn ▶
🤖
Agent
A small program that listens on a port, receives a task, calls an AI model, and responds with a result.
🔗
A2A Protocol
Rules for how agents discover and talk to each other using HTTP + JSON-RPC.
🆔
AgentCard
A JSON file at /.well-known/agent-card.json that says who the agent is and what it can do.
⚡
Skill
A declared capability — e.g., "generate_tests" or "implement_code".
💬
Message
Text sent between agents via JSON-RPC POST requests.
🎓
Orchestrator
The "boss" that chains agents together, passing each output to the next agent.

How agents communicate

 Orchestrator                           Agent (port 9001)
     |                                      |
     |  1. GET /.well-known/agent-card.json  |
     | ----------------------------------->  |
     |  <--- JSON: name, skills, URL        |
     |                                      |
     |  2. POST / (JSON-RPC message)         |
     | ----------------------------------->  |
     |  <--- Result text                    |

Setup
Setup ▶

Prerequisites

🐍
Python 3.11+
Check: python3 --version
🔑
Gemini API Key
Free from aistudio.google.com/apikey

Step 1: Get a free API key

Go to aistudio.google.com/apikey, click "Create API Key", copy it. No credit card needed.

Step 2: Clone and install

$ git clone https://github.com/YOUR_USERNAME/a2a-tdd-agents.git
$ cd a2a-tdd-agents
$ pip install -r requirements.txt

Step 3: Configure API key

$ cp .env.example .env

Edit .env and paste your key:

GEMINI_API_KEY=paste-your-key-here
LLM_MODEL=gemini-3.5-flash-lite

Step 4: Verify

$ python3 -c "from common import llm_call; print(llm_call('Say one word.', 'Hello'))"

You should see a word like "Hello". If you get an error, check your API key.

Running the TDD Pipeline
Run ▶

One-command run

$ ./run_agents.sh "Users can register with email and password"

Step-by-step (for learning)

Terminal 1 — Start the agents:

$ python3 -m agents.spec_analyst.server &
$ python3 -m agents.test_writer.server &
$ python3 -m agents.code_writer.server &
$ python3 -m agents.mr_creator.server &

Terminal 2 — Run the orchestrator:

$ python3 orchestrator.py "Users can register with email and password"

How Every Agent Is Built
Learn ▶

Every agent follows the same two-file pattern:

File 1: agent.py — The Brain

from common import llm_call

SYSTEM_PROMPT = """You are a [role]. Given [input], produce [output]..."""

class MyAgent:
    def do_work(self, input_text: str) -> str:
        return llm_call(SYSTEM_PROMPT, input_text)

One class. One method. One LLM call. That's it.

File 2: server.py — The Body

# 1. Wrap the agent in an A2A Executor
class MyExecutor(AgentExecutor):
    async def execute(self, context, event_queue):
        input = context.get_user_input()
        result = self.agent.do_work(input)
        message = Message(role=Role.ROLE_AGENT, parts=[Part(text=result)])
        await event_queue.enqueue_event(message)

# 2. Declare an AgentCard (identity + skills)
agent_card = AgentCard(
    name="MyAgent",
    skills=[AgentSkill(id="my_skill", ...)],
    supported_interfaces=[AgentInterface(url="http://...", protocol_binding="JSONRPC")],
)

# 3. Create routes and run
routes = create_agent_card_routes(agent_card) + create_jsonrpc_routes(handler, rpc_url="/")
app = Starlette(routes=routes)
uvicorn.run(app, port=9001)
To create a new agent: Copy any existing agent folder, change the system prompt in agent.py, and change the port + skill in server.py.
